NBA Prediction System - Command Reference Guide
Core Commands
1. Full Pipeline (Complete Analysis)
bash# Standard full run - fetch data, train model, make predictions
python main.py

# Full run without downloading new data (use cached)
python main.py --no-update

# Full run with hyperparameter tuning (slower, better accuracy)
python main.py --tune

# Full run with backtesting validation
python main.py --backtest
2. Quick Prediction Mode
bash# Fast predictions using cached data (no retraining)
python main.py predict

# Quick predictions with custom max bets
python main.py predict --max-bets 3
3. Data Collection
bash# Fetch all data (historical + current + upcoming)
python fetch_data.py

# Fetch only upcoming games
python fetch_upcoming_games.py
4. Performance Tracking
bash# Update predictions with actual game results
python update_results.py

# Check last 7 days of results
python update_results.py --days 7

# Update without showing performance report
python update_results.py --no-report

# Update and export to CSV
python update_results.py --export

# View performance tracker demo
python performance_tracker.py
5. Testing & Demos
bash# Test betting strategy calculations
python betting_strategy.py

# Test free NBA APIs
python free_nba_apis.py

# Test data processor
python data_processor.py

# Test model utilities
python model_utils.py

Important Notes

✅ Best Practices:

Run update_results.py daily
Monitor performance tracker alerts
Start with --min-edge 0.08 (conservative)
Use --max-bets 2-3 initially
Review calibration weekly

🚫 Don't:

Skip the --no-update flag without checking data freshness
Ignore performance tracker warnings
Bet more than 3% per game
Chase losses by lowering min-edge
