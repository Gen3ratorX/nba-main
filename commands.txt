🚀 Shell Aliases (Recommended)
Add to ~/.zshrc or ~/.bashrc:
bash# Navigate to project and activate venv
alias nba-cd="cd ~/nba-main && source venv/bin/activate"

# Ultimate System (Best)
alias nba="cd ~/nba-main && source venv/bin/activate && python ultimate.py"
alias nba-tomorrow="cd ~/nba-main && source venv/bin/activate && python ultimate.py --tomorrow"
alias nba-all="cd ~/nba-main && source venv/bin/activate && python ultimate.py --show-all"

# Individual Components
alias nba-ml="cd ~/nba-main && source venv/bin/activate && python today.py"
alias nba-totals="cd ~/nba-main && source venv/bin/activate && python totals_predictor.py"

# Training
alias nba-train="cd ~/nba-main && source venv/bin/activate && python main.py --days-back 30 && python train_totals_model.py"
alias nba-train-ml="cd ~/nba-main && source venv/bin/activate && python main.py --days-back 30"
alias nba-train-totals="cd ~/nba-main && source venv/bin/activate && python train_totals_model.py"

# Tracking
alias nba-update="cd ~/nba-main && source venv/bin/activate && python update_results.py --days 1"
alias nba-weekly="cd ~/nba-main && source venv/bin/activate && python update_results.py --days 7"

# Full refresh
alias nba-refresh="cd ~/nba-main && source venv/bin/activate && python main.py --days-back 60 && python train_totals_model.py && python ultimate.py"
Reload: source ~/.zshrc
Then simply type:

⚠️ Important Notes
✅ Best Practices:

Run python ultimate.py daily for picks
Run python update_results.py --days 1 daily to track
Retrain models weekly: python main.py --days-back 30 + python train_totals_model.py
Start with --min-edge 0.08 (conservative)
Use --max-bets 2-3 initially
Review calibration weekly

🚫 Don't:

Ignore performance tracker warnings
Bet more than 3% per game
Chase losses by lowering min-edge
Skip daily result updates
Trust edges >10% without verification

⚠️ Before Real Money:
bash# Paper trade for 100+ games first
python ultimate.py              # Get picks daily
python update_results.py --days 1  # Track without betting

# After 100+ tracked predictions, review:
python update_results.py --days 30 --export
